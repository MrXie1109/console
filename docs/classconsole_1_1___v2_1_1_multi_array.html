Detailed Description

template<class T, size_t... Dims>
class console::_V2::MultiArray< T, Dims >

编译期固定维度的多维数组(堆版本)。

Template Parameters
T元素类型。
Dims各维度大小(可变参数，至少一个维度)。

MultiArray 使用堆内存存储，支持视图语义：

  • 默认构造分配堆内存，对象拥有数据；
  • 子数组访问返回视图(浅拷贝)，共享同一份数据；
  • 拷贝构造深拷贝，返回独立拥有者；
  • 移动构造转移所有权，源对象变为空视图。
    Note
    维度信息在编译期确定，所有元素连续存储于堆内存中。 视图是轻量级对象(仅包含指针和布尔标志)，可高效传递。
