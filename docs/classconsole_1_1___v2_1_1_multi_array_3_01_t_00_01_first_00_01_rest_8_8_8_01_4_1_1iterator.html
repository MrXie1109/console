Detailed Description

template<class T, size_t First, size_t... Rest>
class console::_V2::MultiArray< T, First, Rest... >::iterator

随机访问迭代器，遍历第一维的子数组。

迭代器解引用时构造临时视图，不指向真实存在的对象。 operator-> 返回 shared_ptr<value_type> 以确保生命周期。
