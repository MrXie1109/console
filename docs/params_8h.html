Detailed Description

提供参数包包装器(Params)和便捷构造函数(params)，用于将多个参数打包并支持延迟应用。

在没有 std::index_sequence 和 std::apply 的 C++11 环境下，提供一个可用的替代品。 采用递归模板结构实现参数包的存储和延迟调用。
