Detailed Description

template<class... Ts>
class console::Union< Ts >

类型安全的可判别联合体。

类似于 std::variant，但实现方式更底层。 在任何时刻，Union 要么为空 (默认构造后)，要么存储 Ts... 中某一类型的值。 所有操作均基于函数指针表实现，以减小代码体积。

Template Parameters
Ts允许存储的类型列表，不能包含重复类型或 void (除非作为唯一类型)。
