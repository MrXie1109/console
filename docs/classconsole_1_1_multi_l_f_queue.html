Detailed Description

template<class T, class Alloc = std::allocator<T>, size_t RobinTimes = 2>
class console::MultiLFQueue< T, Alloc, RobinTimes >

多队列版本的 LFQueue，将数据分布到多个独立的 LFQueue 中以提高并发性能。

Template Parameters
T队列中元素的类型。
Alloc分配器类型，默认为 std::allocator<T>。
RobinTimespop 轮询次数，默认为 2。
Note
通过多个子队列减少竞争者数量，降低自旋等待的概率。 推送时使用线程本地索引进行负载均衡，弹出时使用轮询策略遍历所有子队列。
Warning
不保证多线程的全局 FIFO 顺序，仅保证每个线程内部的 FIFO 顺序。

从队列中弹出数据。

Parameters
output弹出的数据将存储在此处。
Returns
如果成功弹出数据，则返回 true；否则返回 false。
Note
使用轮询计数器 round_robin_ 选择起始子队列，然后依次遍历所有子队列， 直到找到一个非空的子队列并成功弹出数据。如果所有子队列均为空，则返回 false。 可能佯败，如果在询问过一个子队列之后改子队列才被 push，则发生佯败。
