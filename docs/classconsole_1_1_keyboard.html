◆ handleEscape()

Key console::Keyboard::handleEscape ( )
inlineprivate

处理以 ESC (27) 开头的转义序列(主要针对 Linux 终端)。

Returns
如果识别为方向键则返回对应 Key；否则返回 Key::Esc。

在 Linux 终端下，方向键会发送 "\033[A"、"\033[B" 等三字节序列。 本函数通过非阻塞 poll 检查后续输入，若在 5ms 内读到 "[A"-"[D]" 则转为方向键，否则视为普通 Esc 键。

◆ parse()

Key console::Keyboard::parse ( int raw)
inlineprivate

将原始扫描码解析为 Key 枚举值。

Parameters
raw原始按键整数值(来自 readRaw 或 readRawBlock)。
Returns
对应的 Key 枚举值；若无法识别则返回 Key::Unknown。

处理以下情况：

  • 字母字符(自动将小写转为大写)
  • 数字字符
  • 空格、回车、Esc、退格、Tab
  • Windows 平台扩展键(方向键、F1-F12，其扫描码为 0xE0 或 0x00)
  • 其他平台无法识别的键返回 Unknown

◆ readRaw()

int console::Keyboard::readRaw ( )
inlineprivate

读取一个原始按键值(非阻塞)。

Returns
如果按键存在，返回按键的整数扫描码；否则返回 -1。

Windows 平台使用 _kbhit() 和 _getch()； Linux 平台使用 poll() 和 read()。
