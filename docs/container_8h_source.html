42namespace console {}
adapter.h
提供带有值返回 pop 操作的容器适配器包装类。
box.h
提供可存储任意类型的异构容器(Box)和类型擦除包装器(Item)。
cow.h
提供 Cow 类实现写时复制操作。
maybe.h
提供类似 std::optional 的可选值容器 Maybe，支持空状态(nothing)。
multiarray.h
提供编译期维度固定的多维数组容器 MultiArray，支持任意维度和元素级算术/逻辑/位运算。
console
本库所有组件所在的顶层命名空间。
result.h
提供类似 Rust 的 Result 类型，用于表示成功(Ok）或失败(Err）的结果。
union.h
提供类型安全的可判别联合体 (Tagged Union)。
view.h
提供容器的非拥有视图(View)，支持区间切片和便捷的工厂函数。
