Detailed Description

template<class... Ts>
class console::Params< Ts >

递归参数包包装器，将多个参数存储为值类型，并支持通过 apply 方法延迟调用。

空参数特化版本。

Template Parameters
Ts参数类型包，可以是任意数量、任意类型。

采用递归模板结构，每个 Params 实例存储一个值及其余参数。 通过 apply 方法可以将存储的所有参数传递给一个可调用对象。 常用于参数捕获、延迟求值或适配需要多个参数的接口。

Note
这是非特化版本的声明，具体实现见特化和递归特化版本。

用于处理无参数的情况，提供空的 apply 方法。
