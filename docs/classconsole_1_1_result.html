Detailed Description

template<class T, class E>
class console::Result< T, E >

表示可能成功或失败的结果，类似于 Rust 的 Result 类型。

Template Parameters
T成功值的类型。
E错误值的类型。

Result 要么包含一个 T 类型的成功值(Ok），要么包含一个 E 类型的错误值(Err）。使用对齐的字节缓冲区存储两者之一， 避免了额外的堆分配。访问错误状态的成功值会抛出异常。
