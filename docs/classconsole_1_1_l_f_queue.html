Detailed Description

template<class T, class Alloc = std::allocator<T>>
class console::LFQueue< T, Alloc >

基于自旋的高性能 FIFO 队列，支持多生产者/多消费者并发。

Template Parameters
T队列中元素的类型。
Alloc分配器类型，默认为 std::allocator<T>。
Note
通过原子 exchange 实现轻量级互斥，临界区极短 (~3-10ns)。 提供 Lock-Free 进度保证 (至少一个线程能前进)，但不是 Wait-Free。

template<class Iterator>
void console::LFQueue< T, Alloc >::push ( Iterator begin,
size_t count )
inline

将大批数据推送到队列中。

Parameters
begin数据迭代器的起始位置。
count要推送的数据数量。
Note
提前批量构造所有节点，然后一次性链接为完整链表并挂载至队尾， 从而将临界区压缩为两次原子操作，显著降低多线程竞争下的自旋开销。 若构造过程中抛出异常，会先销毁已构造的节点再抛出，保证不会泄漏内存。 相比逐元素 push 减少了对 tail_ 的独占/释放次数，批量场景下吞吐更高。
