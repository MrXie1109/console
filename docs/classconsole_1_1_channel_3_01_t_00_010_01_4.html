显式转换为布尔值。

Returns
若通道已关闭且没有剩余数据，返回 false；否则返回 true。
Note
注意，验明通道为 true 后仍然可能出现问题，因为验明和读值不是原子的。 得到 true 只能表明验明前管道有效，不代表读取时有效。
