Detailed Description

template<class Ret>
class console::Coroutine< Ret()>

无参数协程的特化，可用作输入迭代器。

返回引用无参数协程的特化，可用作输入迭代器。

每次调用 operator() 获取下一个产出值。该特化支持范围 for 循环 (通过 begin() 和 end())，也提供迭代器语义。 当协程结束 (抛出 StopIteration)后， 迭代被视为到达末尾。

Template Parameters
Ret产出值的类型。

每次调用 operator() 获取下一个产出引用。该特化支持范围 for 循环 (通过 begin() 和 end())，也提供迭代器语义。 当协程结束 (抛出 StopIteration)后， 迭代被视为到达末尾。
