Detailed Description

提供编译期维度固定的多维数组容器 MultiArray，支持任意维度和元素级算术/逻辑/位运算。

MultiArray 使用堆内存存储，支持视图语义、 扁平化迭代器 fbegin/fend、元素级运算(包括数组与数组、数组与标量)、 统计函数(sum/min/max/all/any)等。
