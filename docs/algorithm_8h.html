Detailed Description

算法头文件，包装 STL 的标准算法为函数对象。

解决标准库中算法为模板函数无法被存储于对象中的问题， 同时，函数对象的效率略微优于函数指针，提高了效率。

Note
可以接入 Generator 的 algorithm 终端中。
