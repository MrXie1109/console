Detailed Description

轻量级 C++ 协程/生成器宏实现。

一个极度轻量、基于宏的状态机协程实现，仅占用一个 int 状态变量。 通过宏，将普通函数转换为可多次调用、每次产生一个值的生成器。 可以使用持久化变量保存状态，调用方在每次调用后得到下一个产出值。
