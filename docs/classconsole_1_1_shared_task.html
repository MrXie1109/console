Detailed Description

template<class T>
class console::SharedTask< T >

异步任务类，用于在后台线程中执行任务 (共享版)。

Template Parameters
T任务返回值的类型。
Note
SharedTask 的限制相对于 Task 更少，如：
  • 线程安全，无需手动同步。
  • 可多次获取结果，不会抛出异常。
  • 可拷贝，也可移动。 但可能略慢。
