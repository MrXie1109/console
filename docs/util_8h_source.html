algorithm.h
算法头文件，包装 STL 的标准算法为函数对象。
collide.h
在运行时实现双重分派(double dispatch)。
coroutine.h
轻量级 C++ 协程/生成器宏实现。
crypto.h
提供SHA256、MD5、Base64和AES加密功能的加密库。
defer.h
RAII的作用域宏，在退出作用域时按逆序执行推迟的代码。
gen.h
生成器模式头文件。
gextra.h
生成器库扩展功能。
iter.h
提供些许关于迭代器的拓展功能。
logging.h
提供带颜色和级别的日志记录功能。
console
本库所有组件所在的顶层命名空间。
params.h
提供参数包包装器(Params)和便捷构造函数(params)，用于将多个参数打包并支持延迟应用。
syscmd.h
跨平台系统命令执行模块。
test.h
极简C++测试框架，基于宏与异常实现断言与结果统计。 支持单元测试的注册、执行、结果输出与汇总报告。
time.h
提供时间度量、计时、休眠和日期时间格式化功能。
